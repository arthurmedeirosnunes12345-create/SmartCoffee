Comando Git

git init - Inicializa um novo repositório Git

git add - Ira adicionar esse arquivo em processo de envio

git commit - Cria um novo commit com as alterações adicionadas

git status - Exibe o status atual do repositório

git log - Exibe o histórico de commits

git branch - Gerencia ramos (branches) do repositório

git merge - Mescla alterações de um branch para outro

git remote -v -visualizar conexão remote git

Por que não criar o README.md?

Por que nosso projeto já possui um histórico. Manter o remoto vazio simplifica a conexão evita históricos diferentes

O que é Origin?

È um nome convencional dado ao repositório remoto

git push - envia a branch main , usa o remoto origin e configura o acompanhamento entre branch local e remote

git push -u origin main

git push - Serão ações futuras
